Area, Price and Wire Mesh Calculator

Factors used: 1 ft = 0.3048 m, 1 sq m = 10.764 sq ft

Length x Width to sq ft and sq m

Feet to meter = ft x 0.3048. Meter to feet = m / 0.3048.

Length converter

Sq m to sq ft = sq m x 10.764. Sq ft to sq m = sq ft / 10.764.

Price per sq m and per sq ft

Price per sq ft = price per sq m / 10.764. Price per sq m = price per sq ft x 10.764. Type in either box and the other updates.

1. Wire mesh weight (kg per sq m)

Weight = Mesh x (Wire dia)^2 / 2

2. Opening of wire mesh (mm)

Opening = 25.4 / Mesh - Wire dia

Weld mesh weight

Weight = 12.7 x (Wire dia)^2 / (Opening + Wire dia) (kg per sq m)

Rate from supplier kg rate and roll weight

Rate per roll = Rate per kg x Weight per roll
Rate per sq m = Rate per roll / Roll area in sq m
Rate per sq ft = Rate per sq m / 10.764

Chain link weight

Weight (kg) = {[(1 / Opening inch) x (Wire dia)^2] / 20} x Length ft x Width ft

Rate from supplier kg rate and roll weight

Rate per roll = Rate per kg x Weight per roll
Rate per sq ft = Rate per roll / Roll area in sq ft
Rate per sq m = Rate per sq ft x 10.764

3. Plain sheet weight

Weight (kg) = Material factor x Thickness mm x Length m x Width m

4. Perforated sheet weight

Rate per nos = Length m x Width m x 10.764 x Supplier rate per sq ft
Open area % = 90.69 x (Hole dia)^2 / (Pitch)^2
Perforated weight = Plain sheet weight - Weight of open area
